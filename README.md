# Consultas SQL y Aplicación Web con Streamlit

Aplicación desarrollada para analizar las ventas de vehículos usados en un perido determinado de tiempo.
Esto permitió dar a conocer a través de gráficos e histogramas la evolución del precio promedio según la condición del vehículo.

🔗 **Aplicación en línea:** [https://tt-project-s7-da-jrg-1.onrender.com](https://tt-project-s7-da-jrg-1.onrender.com)

---

## 🎯 Objetivo del proyecto

Desarrollar una herramienta visual para explorar los resultados de consultas SQL aplicadas sobre bases de datos de negocio, identificando patrones y métricas clave.
La aplicación permite filtrar, comparar y analizar información de forma dinámica.

---

## 🧰 Tecnologías utilizadas

* **Python**
* **Streamlit**
* **SQL**
* **Pandas**
* **Render (deploy)**

---

## 📊 Resultados y aprendizajes

* Conexión entre análisis SQL y visualización interactiva.
* Uso de consultas complejas para análisis de métricas.
* Implementación práctica de una aplicación web de datos.
* Despliegue exitoso en la nube con Render.
